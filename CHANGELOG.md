# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-29

First public release.

### Added

- Portable C99 library for ST7789 panels (240 x 240, RGB565), split into
  `gfx_core`, `gfx_shapes`, `gfx_text`, `gfx_image`, `gfx_widgets`, `gfx_fonts`
  and `gfx_icons`.
- Window + burst painting with clipping to the screen; integer arithmetic only.
- Hardware access through two functions: `gfx_port_cmd()` and `gfx_port_data()`.
- Six anti-aliased fonts derived from DejaVu Sans (Latin-1), 32 icons,
  RGB565 and 1-bit image drawing.
- Widgets: panel, status bar, tab bar, button, switch, check box, slider,
  badge, progress bar, ring gauge, line chart, big number, list item, with a
  dark and a light theme.
- Seven demo pages (Shapes, Text, Icons, Panel, Settings, Light theme, Images).
- `gfx_selftest`: nine bring-up patterns for a real panel.
- Single-header build `single_header/lcd_gfx.h` (stb style, `GFX_IMPLEMENTATION`),
  generated by `tools/make_single_header.py`.
- Host tests against a controller model: 56 library checks and 13 self-test
  checks, run on both the multi-file and the single-header builds.
- Pixel equivalence test: per-page FNV-1a hashes of every demo and self-test
  page, compared between both builds and with `tests/golden/pages.golden`.
- Bus-write benchmark per primitive compared with pixel-by-pixel drawing.
- Strict C99 build (`-Wall -Wextra -pedantic -Werror`) with gcc and clang, and a
  Cortex-M7 cross-compile check when `arm-none-eabi-gcc` is available.
- GitHub Actions workflow for build, test, screenshots and GitHub Pages.
- Documentation site in English and Spanish.
