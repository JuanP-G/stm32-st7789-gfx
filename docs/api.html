API reference

Every public function, grouped by header. Coordinates are in pixels with the origin at the top-left corner; every drawing call is clipped to the 240 x 240 screen.

Conventions

  • Colours are gfx_color_t, an RGB565 uint16_t. Build them with GFX_RGB(r, g, b) (components 0 to 255) or GFX_HEX(0xRRGGBB).
  • x, y is the top-left corner of rectangles, images and text. Circles and arcs take their centre cx, cy.
  • Angles are in degrees: 0 points up and positive angles run clockwise.
  • Strings are UTF-8 and limited to code points up to U+00FF.

Port: gfx_port.h

FunctionDescription
void gfx_port_cmd(uint8_t command)Write one command byte (A0 or D/C low). You implement it.
void gfx_port_data(uint16_t data)Write one data word (A0 or D/C high): an 8-bit parameter after CASET or RASET, a 16-bit pixel after RAMWR. You implement it.

Single header: lcd_gfx.h

The same API in one file. Define GFX_IMPLEMENTATION before the include in exactly one source file; include it plainly everywhere else.

/* gfx_impl.c: the only file that holds the code */
#define GFX_IMPLEMENTATION
#include "lcd_gfx.h"

/* any other file */
#include "lcd_gfx.h"
MacroEffect
GFX_IMPLEMENTATIONCompile the implementation in this translation unit.
GFX_WITHOUT_DEMOLeave out the demo pages and their sample images. Define it for every file that includes the header.
GFX_WITHOUT_SELFTESTLeave out the self-test patterns. Define it for every file that includes the header.

Regenerate the file after changing the sources with make header; make test fails if the committed file is out of date.
